# Isle — Dynamic Island для macOS

> Рабочее название «Isle» — поменяй на своё (поиск/замена по проекту).
> Этот файл читает Claude Code в начале каждой сессии. Положи его в корень проекта.

## Что за приложение

Приложение для macOS, превращающее вырез (notch) MacBook в «Dynamic Island» как на iPhone.
На маках без выреза — рисует такой же остров сверху по центру.
Вдохновение: Vorssaint (инструменты: музыка, скриншот в буфер, камера-зеркало) + Canopy (оформление: тексты песен, экран блокировки, скруглённые углы, рабочий стол).

Автор — студент, пишет приложение через Claude Code. Объясняй решения коротко и просто.

## Технические рамки

- Язык: **Swift 6**, UI: **SwiftUI**, окна и системное: **AppKit**.
- Минимальная macOS: **14.0** (Liquid Glass — только если macOS 26, через `if #available`).
- Только Apple Silicon + Intel (universal), без App Store, **без песочницы** (App Sandbox выключен).
- Проект генерируется через **XcodeGen** (`project.yml`), а не руками в .xcodeproj — так Claude проще его редактировать. `brew install xcodegen`, затем `xcodegen generate`.
- Приложение агент: `LSUIElement = YES` (нет иконки в Dock), есть иконка в строке меню.
- Зависимости (Swift Package Manager), только эти, новые — спрашивать:
  - `sindresorhus/KeyboardShortcuts` — глобальные горячие клавиши
  - `sindresorhus/LaunchAtLogin-Modern` — автозапуск
  - `ungive/mediaremote-adapter` — «что сейчас играет» (MediaRemote закрыт с macOS 15.4)

## Правила работы для Claude Code

1. Работаем **по одному этапу** из плана ниже. Не начинать следующий без команды.
2. После каждого изменения — собрать (`xcodebuild -scheme Isle -configuration Debug build`) и исправить ошибки до чистой сборки.
3. После рабочего этапа — `git commit` с понятным сообщением и `git push` в https://github.com/D1mro/Mac_Bar (ветка `main`).
4. Код простой и читаемый, без лишних абстракций. Каждый сервис — отдельный файл.
5. Не использовать приватные API, кроме этапа 9 (экран блокировки) — там явно помечать `// PRIVATE API`.
6. Все тексты интерфейса — на русском, через `String(localized:)` (чтобы потом добавить английский).

## Подпись (бесплатно, без $99)

Чтобы macOS не сбрасывала разрешения (камера, запись экрана) после каждой сборки:
1. «Связка ключей» → Ассистент сертификатов → Создать сертификат → имя `Isle Dev`, тип «Подпись кода».
2. В `project.yml`: `CODE_SIGN_IDENTITY: "Isle Dev"`, `CODE_SIGN_STYLE: Manual`, `DEVELOPMENT_TEAM: ""`.

## Дизайн

### Принцип
Остров **всегда чистый чёрный `#000000`** — он должен сливаться с физическим вырезом. Liquid Glass / светлая тема — только для раскрытого состояния и только как опция, и даже тогда верхняя полоса высотой с вырез остаётся чёрной.

### Размеры
- Свёрнут: ширина = ширина выреза, высота = `screen.safeAreaInsets.top` (обычно ~32–38 pt). Нижние углы радиус 10.
- Сверху по бокам — маленькие «вогнутые уши» радиусом 6 (inverse corner), чтобы форма плавно вытекала из рамки экрана. Делается кастомным `Shape`.
- Компактный: ширина выреза + по 60 pt с каждой стороны (уведомления), + по 150 pt (смена трека), высота та же.
- Раскрыт: 440 × ~190 pt, нижние углы радиус 30, контент начинается ниже выреза. Иконки вкладок — в полосе выреза слева от него (так под вырезом хватает места плееру).

### Анимация
- Все переходы: `.spring(response: 0.42, dampingFraction: 0.8)`.
- Раскрытие — по наведению курсора (задержка 0.05 сек, зона наведения +6 pt вокруг свёрнутого острова) с хаптиком, закрытие — когда курсор ушёл (задержка 0.3 сек).
- Контент внутри появляется с `.opacity` + лёгким `.scale(0.95)`, позже фона.
- Уведомления (скриншот, зарядка): компактный вид на 1.5 сек, потом обратно.

### Цвета и шрифты
- Текст основной: белый; вторичный: белый 55%; разделители/плашки: белый 8–14%.
- Акцентный цвет плеера — средний цвет обложки альбома (для эквалайзера и прогресса).
- Шрифт: системный SF Pro; цифры (время, проценты) — `.monospacedDigit()`, SF Pro Rounded.
- Размеры: заголовок 14 medium, обычный 12, мелкий 11.
- Иконки: SF Symbols.

### Плеер — макет (раскрытый остров, вкладка «Музыка»)
Ориентир — скриншот `docs/player-reference.png`. Размер ~ 360 × 165 pt, нижние углы 30.
```
┌───────────────────────────────────────────────┐
│ [обложка]  Название трека         [❝]  [☰]   │  ← тексты песен, очередь
│  64×64     Исполнитель            [иконка][▮▮▮]│  ← иконка приложения-источника, звуковой бар
│ 0:30 ━━━━━━━━━━━━━━──────────────────── −1:14 │
│                 ⏸        ⏭           [💻]     │  ← устройство вывода звука
└───────────────────────────────────────────────┘
```
- Обложка 64×64, радиус 14. Название — 17 bold белым, исполнитель — 15 regular белый 55%.
- Справа сверху: кнопки «текст песни» (`quote.bubble`) и «очередь» (`list.bullet`), 15 pt, белый 70%.
- Под ними: **иконка приложения-источника** 20×20 (`NSWorkspace.shared.icon(forFile:)` по bundle id — у Яндекс Музыки будет её жёлтая звезда) и **звуковой бар** — 5 вертикальных капсул шириной 3, зазор 2, высота 4…18 pt, цвет — акцент.
- Прогресс: высота 6, скруглённый, заполненная часть — акцентный цвет, фон — белый 15%. Время слева `0:30`, справа оставшееся `−1:14`, 13 pt, monospacedDigit, белый 55%. Прогресс можно перетаскивать (перемотка).
- Управление: ⏮, ⏸/▶ и ⏭ по центру; свайп вправо/влево — предыдущий/следующий. Клик по обложке — открыть приложение-источник (для видео — браузер). Справа — иконка текущего устройства вывода (`laptopcomputer` / `airpods` / `hifispeaker`), по клику — меню выбора устройства (CoreAudio).
- **Фон**: чёрный + мягкое свечение акцентного цвета из правого нижнего угла (`RadialGradient`, акцент 45% → прозрачный, радиус ~60% ширины). Цвет плавно меняется при смене трека (анимация 0.6 сек).
- **Акцентный цвет**: самый насыщенный из доминирующих цветов обложки (k-means на уменьшенной до 32×32 обложке, отбросить почти чёрные/белые/серые). Если обложка серая — фирменный цвет приложения: Яндекс Музыка `#FFCC00`, Spotify `#1DB954`, Apple Music `#FA2D48`, иначе `#FF9F0A`.
- Кнопка «очередь»: системного API очереди нет → по клику открывает приложение-источник.
- Компактный вид — только при смене трека, на 3 сек: слева обложка 22×22 + название, справа исполнитель. В остальное время остров свёрнут.
- Кнопка «текст песни» переключает плеер на текст (см. этап 7).

### Состояния острова (state machine)
```
idle (свёрнут)
 ├─ compact(.track)        — сменился трек: обложка + название, исполнитель (3 сек)
 ├─ compact(.notification) — «Скопировано», «Зарядка 82%» и т.п., 1.5 сек
 └─ expanded(tab)          — вкладки: Музыка | Камера | Инструменты
```
Приоритет: expanded > notification > track > idle.

## План этапов

Каждый этап — отдельная сессия Claude Code. Готово = сборка без ошибок + проверено руками + commit.

### Этап 0 — Каркас
- `project.yml`, пустое приложение-агент, иконка в строке меню с пунктом «Выйти».
- Подпись сертификатом `Isle Dev`. git init, .gitignore.
- **Готово когда:** приложение запускается, в Dock его нет, в меню — иконка.

### Этап 1 — Остров
- `IslandWindow`: NSPanel без рамки, `level = .statusBar + 1`, прозрачный фон, `collectionBehavior = [.canJoinAllSpaces, .stationary, .fullScreenAuxiliary]`, не забирает фокус.
- Позиция по центру сверху главного экрана, размер выреза через `safeAreaInsets` и `auxiliaryTopLeftArea/RightArea`. Нет выреза — капсула 190×32.
- `IslandShape`, state machine, раскрытие по наведению, анимации.
- Окно пропускает клики там, где острова нет (иначе блокирует меню).
- Прячется в Mission Control (`.transient`) и не попадает на скриншоты (`sharingType = .none`).
- Перестраиваться при смене мониторов (`NSApplication.didChangeScreenParametersNotification`).
- **Готово когда:** остров незаметен в покое, плавно раскрывается при наведении, не мешает строке меню.

### Этап 2 — Скриншот в буфер
- Глобальная горячая клавиша (по умолчанию ⌥⇧4, настраивается).
- Свой оверлей выбора (`Screenshot/ScreenshotOverlay`): протянуть — область, клик по окну — окно по рамкам, прозрачная кнопка «Весь экран» по центру чуть сверху, Esc — отмена. Снимок — `/usr/sbin/screencapture -c -R …` / `-c -o -l <id>` сразу в буфер.
- Перед снимком проверить доступ «Запись экрана» (`CGPreflightScreenCaptureAccess`), без него screencapture даёт пустую картинку.
- После успеха: уведомление «Скопировано» в острове + лёгкий хаптик.
- Кнопка «Скриншот» во вкладке «Инструменты».
- **Готово когда:** нажал ⌥⇧4 → выделил → вставил в Telegram.

### Этап 3 — Камера-зеркало
- Вкладка «Камера»: `AVCaptureSession` + превью, зеркально отражённое, скруглённые углы 16.
- Камера включается только когда вкладка открыта, выключается при закрытии острова (зелёная лампочка не должна гореть зря).
- Окошко-зеркало 320×180 под вырезом по ⌥⇧3, не раскрывая остров (`Camera/CameraMirrorWindow`); повторное нажатие, Esc или клик — закрыть.
- `CameraService` считает «зрителей» (вкладка + окошко): камера горит, пока открыт хотя бы один.
- `NSCameraUsageDescription` в Info.plist.
- **Готово когда:** открыл вкладку — видишь себя, закрыл — лампочка погасла.

### Этап 4 — Музыка
- `NowPlayingService` через mediaremote-adapter: название, исполнитель, обложка, длительность, позиция, играет/пауза, bundle id приложения-источника.
- Работает с любым плеером, который виден в Пункте управления → «Исполняется» (Яндекс Музыка, Spotify, Apple Music, браузер).
- Запасной вариант, если адаптер не работает: AppleScript для Spotify и Music.
- Адаптер лежит собранным в `Vendor/MediaRemoteAdapter` (версия в `VERSION`), пересборка — `scripts/build-mediaremote-adapter.sh` (нужен cmake). Фреймворк встраивается в `Contents/Frameworks` без линковки, скрипт — в Resources; запуск: `/usr/bin/perl mediaremote-adapter.pl <framework> stream --micros`.
- Звуковой бар на этом этапе — псевдо-анимация, настоящий звук — этап 4.5.
- Вёрстка плеера — строго по разделу «Плеер — макет» ниже.
- **Готово когда:** Яндекс Музыка, Spotify и Apple Music отображаются и управляются.

### Этап 4.5 — Живой звуковой бар
- `AudioVisualizerService`: настоящий звук приложения-источника, не фейковая анимация.
- Core Audio **process tap** (macOS 14.2+): pid источника из bundle id (`NSRunningApplication`) → `kAudioHardwarePropertyTranslatePIDToProcessObject` → `CATapDescription(stereoMixdownOfProcesses:)` → `AudioHardwareCreateProcessTap` → приватный aggregate device → IOProc.
- В IOProc: буфер 1024 сэмпла → FFT через Accelerate (`vDSP`) → 5 полос по логарифмической шкале (≈60–250, 250–500, 500–2k, 2k–4k, 4k–12k Гц) → нормализация 0…1.
- Сглаживание: подъём быстро (0.6), спад медленно (0.15) — чтобы бары «прыгали», а не дрожали. Обновление UI 60 fps (`TimelineView(.animation)`), расчёты не на main thread.
- Info.plist: `NSAudioCaptureUsageDescription` («Чтобы звуковой бар двигался в такт музыке»).
- Tap включён только когда играет музыка и остров видим; на паузе — бары плавно опускаются до точек.
- Нет разрешения или macOS < 14.2 → красивая псевдо-анимация (синусы со сдвигом фаз), без ошибок.
- Если источник — браузер, тапается весь браузер (это нормально).
- **Готово когда:** бары явно попадают в бочку и вокал, на паузе замирают, CPU < 3%.

### Этап 5 — Система и детали
- Зарядка: подключил кабель → уведомление с процентом (IOKit `IOPSNotificationCreateRunLoopSource`).
- Погода во вкладке «Инструменты» (Open-Meteo, город — в настройках).
- Хаптики `NSHapticFeedbackManager` (вкл/выкл в настройках).
- Скруглённые нижние углы экрана: два маленьких окна с чёрными четвертькругами, `ignoresMouseEvents = true`.

### Этап 6 — Настройки
- Окно настроек (SwiftUI `Settings`): горячая клавиша, автозапуск, хаптики, углы, город, тема раскрытого острова (Чёрная / Liquid Glass на macOS 26).
- Первый запуск: экран приветствия с запросом разрешений по очереди.

### Этап 7 — Тексты песен
- `LyricsService`: запрос к `https://lrclib.net/api/get` по исполнителю/треку/длительности, парсинг LRC.
- Текущая строка в раскрытом плеере, подсветка по времени, кэш на диске.
- Сделано вместе с этапом 4: стиль Яндекс Музыки — крупные жирные строки, текущая яркая, остальные приглушены, плавная прокрутка, клик по строке — перемотка.

### Этап 8 — Рабочий стол
- Смена обоев из приложения (`NSWorkspace.setDesktopImageURL`).
- Живые обои: окно на уровне рабочего стола (`kCGDesktopWindowLevel`) с `AVPlayerLayer`, зациклено, пауза при работе от батареи.
- Виджеты на рабочем столе (часы, музыка, погода), перетаскиваемые.

### Этап 9 — Экран блокировки (эксперимент)
- Плеер, часы и текст песни поверх экрана блокировки.
- Требует приватного фреймворка SkyLight → вынести в отдельный модуль, выключено по умолчанию, тумблер «Экспериментально».
- Может сломаться при обновлении macOS — это нормально.

### Этап 10 — Выпуск на GitHub (бесплатно)
- GitHub Actions (`macos-latest`): сборка Release, ad-hoc подпись, упаковка в `.zip`/`.dmg`, загрузка в Releases по тегу `v*`.
- README: что умеет, скриншоты/гифка, установка и обход Gatekeeper:
  «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть»
  или `xattr -dr com.apple.quarantine /Applications/Isle.app`.
